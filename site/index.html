Set it up in 4 steps

Your phone or laptop must be on the same Wi‑Fi network as the computer running OBS.

Install the plugin

  1. Close OBS, then double-click vcast-…-windows-x64-Installer.exe.
  2. If Windows says "Windows protected your PC", click More info → Run anyway. The installer isn't code-signed yet.
  3. Click Install. The installer also allows OBS through Windows Firewall so phones can reach it.
  1. Close OBS, then double-click vcast-…-macos-universal.pkg.
  2. If macOS blocks it, right-click the .pkg → Open → Open. You can also go to System Settings → Privacy & Security → Open Anyway.
  3. When OBS starts, allow Local Network access and incoming connections if asked.
  1. Run sudo apt install ./vcast-*-x86_64-linux-gnu.deb
  2. Start OBS.

Add the screen receiver to your scene

In OBS, open Docks → Vcast and click Add screen receiver to scene. You can also add it from Sources → + → Vcast Screen Receiver. The source joins your live scene and fills the screen automatically. Use Fit to screen any time to snap it back.

Cast from your device

  1. Open Control Center (Mac: the Control Center icon in the menu bar).
  2. Tap Screen Mirroring.
  3. Choose Vcast (your computer's name). Your screen and sound appear in OBS.
  1. Install the Vcast app from the download above. You can also open https://<your-PC>:8443/android on the phone. When asked, allow installing apps from your browser.
  2. Open Vcast, tap your OBS computer, then tap Start now.
  3. Tip: add the Cast to OBS tile to Quick Settings (swipe down twice → pencil icon → drag the tile). After that, casting is one tap.

Android's built-in "Cast" button only works with Google-certified devices, so OBS can't appear there. The Vcast app and its tile take its place.

  1. In the Vcast dock, find the cast page address, e.g. https://192.168.1.20:8443.
  2. Open it on the laptop in Chrome, Edge, Firefox or Safari. The first time, the browser warns about the certificate. Click Advanced → Proceed. Vcast makes a private certificate on your computer.
  3. Press Share screen, pick a screen or window, and tick share audio if you want sound.

Go live

The cast appears in your Program output. Stream, record or project it like any other source. To show two phones side by side, add a second receiver and give it a different name in its properties.

Troubleshooting & FAQ

My iPhone doesn't show "Vcast" in Screen Mirroring
  • Make sure the iPhone and the OBS computer are on the same Wi‑Fi network, with no VPN on either.
  • Guest networks and "AP/client isolation" on some routers hide devices from each other.
  • The Vcast Screen Receiver source must exist in OBS with Accept AirPlay ticked.
  • Windows: allow OBS through the firewall. Mac: allow OBS under Privacy & Security → Local Network.
Why isn't OBS in my Android phone's Cast menu?

The Cast menu (Google Cast / Chromecast) only lists devices that carry a security certificate issued by Google, which no PC software can get. The free Vcast app with its Cast to OBS Quick Settings tile gives you the same one-tap experience. On Windows you can also use the built-in Wireless Display receiver (Settings → System → Projecting to this PC) for Samsung Smart View / Miracast, then add a Window Capture in OBS.

The picture is choppy or delayed

Move closer to the router or use 5 GHz Wi‑Fi. On laptops, choose 720p on the cast page. Expect a little delay (well under a second on a good network).

OBS says the plugin failed to load

Update OBS to 32.2 or newer (Help → About). Then check Help → Log Files → View Current Log for lines starting with [vcast].

Is it free? Is it safe?

Yes. Vcast is open source under the GPL-3.0 licence. Everything stays on your local network; nothing goes through the internet.
